## 🚀 Featured Projects

### 1. AIUB UniAssist

**Hybrid RAG-Powered University Information and Course Management System**

An AI-powered university information system that combines knowledge retrieval with database-backed academic management.

**Key features**
- REST APIs for department, student, course, and enrollment management
- Hybrid retrieval using BGE-M3 embeddings and BM25
- Reciprocal Rank Fusion (RRF) to combine retrieval results
- Qdrant vector search and a university-specific knowledge base
- LLM integration through LangChain and OpenRouter

**Tech stack:** FastAPI, React, SQLAlchemy, SQLite, BGE-M3, Qdrant, BM25, LangChain

[🌐 Live Demo](https://aiub-uni-assist.vercel.app/) · [📂 GitHub Repository](https://github.com/Kazi-Sadman/AIUB-UniAssist-A-Hybrid-RAG-Powered-University-Information-and-Course-Management-System)

### 2. SMS Spam Classifier

A machine learning application for classifying SMS messages as spam or legitimate messages.

**Key features**
- Text preprocessing and TF-IDF feature extraction
- Comparison of machine learning and ensemble approaches
- Interactive single-message and batch prediction
- Model evaluation and cross-dataset validation

**Tech stack:** Python, Scikit-learn, NLTK, TF-IDF, Streamlit

[🌐 Live Demo](https://smsspamclassifier-2ozcpwt4scvdrtrnvdytug.streamlit.app/) · [📂 GitHub Repository](https://github.com/Kazi-Sadman/sms_spam_classifier)

### 3. Movie Recommendation System

A content-based movie recommendation application that finds movies with similar textual features.

**Key features**
- TF-IDF feature extraction
- Cosine similarity for recommendation ranking
- TMDB API integration
- Separate frontend and FastAPI backend deployment

**Tech stack:** Python, FastAPI, Scikit-learn, TF-IDF, cosine similarity, Streamlit, TMDB API

[🌐 Live Demo](https://movie-recommendation-app-sfxg.onrender.com/) · [📘 API Documentation](https://movie-recommendation-api-7910.onrender.com/docs) · [📂 GitHub Repository](https://github.com/Kazi-Sadman/Movie-Recommendation-System)
